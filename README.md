# ForestBean Personal Space

一个可直接部署到 GitHub Pages 的零依赖个人主页模板。

## 内容更新

所有个人资料、人生阶段、作品、工具和目标都集中在 [src/config.js](./src/config.js)。替换其中的示例文字、邮箱和链接即可。

图片建议放入 `assets/images/`，然后在 `src/config.js` 中填写相对路径；当前版本使用 CSS 绘制的抽象背景，因此无需图片也能直接运行。

## 本地预览与部署

直接双击 `index.html` 即可预览。将仓库推送至 GitHub 后，在仓库 Settings → Pages 中选择从分支部署（`main` / root），即可发布。
