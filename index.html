浏览器权限获取演示

通过 JavaScript API 请求并管理各类浏览器权限的完整示例

注意：需在 HTTPS 或 localhost 环境下运行

使用前须知

  • • 敏感权限（摄像头、麦克风、地理位置等）必须在安全上下文（HTTPS 或 localhost）中运行
  • • 权限请求必须由用户手势触发（如点击按钮），禁止页面加载时自动调用
  • • 用户拒绝权限后，后续调用将直接失败，需要引导用户在浏览器设置中手动开启
  • • 不同浏览器对权限 API 的支持程度可能略有差异，建议在 Chrome/Edge/Firefox 最新版测试

getUserMedia API

async function requestMedia() { try { const stream = await navigator.mediaDevices.getUserMedia({ video: { width: { ideal: 1280 }, height: { ideal: 720 } }, audio: true }); document.querySelector('video').srcObject = stream; console.log('权限获取成功'); } catch (error) { if (error.name === 'NotAllowedError') { alert('用户拒绝了权限'); } } }

function toggleFullscreen() { if (!document.fullscreenElement) { document.documentElement.requestFullscreen() .catch(err => { console.log('全屏请求被拒绝:', err); }); } else { document.exitFullscreen(); } } // 监听全屏状态变化 document.addEventListener('fullscreenchange', () => { if (document.fullscreenElement) { console.log('进入全屏模式'); } else { console.log('退出全屏模式'); } });
