# 06 · DIY 功能与工具

## 定位

个人主页保留轻量、可即时使用的小工具；较大的创作型功能使用独立入口和独立页面承载，避免把复杂操作挤进主页栏目。

## 页面层级

- 主体导航保留「DIY 工具」：文字计数、JSON 格式化等轻量工具继续留在现有页面。
- 新增「DIY 功能」栏目作为大型功能导航页，以卡片介绍每项功能。
- 点击大型功能卡片后进入独立全屏页面，拥有自己的 URL 和页面布局。
- 图片转拼豆图作为首个大型功能入口，提供图片上传、拼豆宽度与颜色数设置、网格预览、颜色用量和 PNG 下载。
- 独立工具页使用轻量的主题化 Header、工作区 Body 和 Footer；显示作者 Abin，并可返回 DIY 功能目录。
- 转换在浏览器 Canvas 中完成，图片不上传到服务器。

## 实现约定

- 使用 Vue Router 管理独立功能页路由，支持直接访问和刷新。
- 功能目录与轻量工具页分开，保留现有文字计数和 JSON 格式化交互。
- 页面颜色延续 Forest Bloom 的雾蓝、柔粉与暖白色，但独立功能页可按功能需要扩展自己的布局。
- 每次项目讨论或实现后，将确定的设计决策和范围同步记录到 `doc/`。

## 拼豆转换参考

- [BeadMapper](https://www.beadmapper.com/) 展示了图片上传、颗粒尺寸、调色板、结果预览和导出的典型流程，可作为交互参考。
- [PatternBeads](https://www.patternbeads.com/pattern-maker) 以实体拼豆调色板进行颜色匹配，说明颜色映射应优先对齐实际可用的拼豆颜色。
- 首版默认使用图片提取的 RGB 色板，不绑定拼豆品牌；颜色图例完整显示 RGB(r, g, b) 数值。
- 已选图片时，拼豆宽度、颜色数和网格开关均需在拖动或切换时实时更新预览与颜色统计，不要求用户额外点击生成按钮。
- 拼豆宽度支持 16–256 颗；颜色数量支持 4–36 色，滑块旁提供数字输入并联动更新。
- PNG、PDF、SVG 导出均由拼豆图和颜色用量图例组成，图例记录当前选定色值格式及所需颗数。
- 导出格式以 PNG、PDF、SVG 三个 Radio 单选项呈现，默认选中 PNG。
- 导出支持 PNG、SVG 和浏览器打印为 PDF；SVG 适合平板缩放查看，均附颜色用量图例。
- 每种导出格式在单选项旁说明适用场景；SVG 必须以 SVG 矩形元素逐颗绘制拼豆和网格，不可将 PNG 当作图片嵌入。SVG 与 PNG 共用标题、图案缩放尺寸、上方留白、下方三列图例、色块尺寸、文字和间距，保持版式基本一致。
- 导出格式的补充说明需使用浅雾蓝底色、柔和边线和易读行距，明确指出各格式的使用理由。
- 三个格式选项及说明始终同时显示，采用等宽固定网格；切换只改变选中样式，不改变布局尺寸。
- RGB 图例的显示方式固定选项同样使用该单选卡片样式，顺序为 #RRGGBB、RGB(r, g, b)、0xRRGGBB，默认 #RRGGBB；选择同步作用于预览和所有导出格式。

## 当前转换实现

1. 文件通过浏览器文件输入读取，并以本地 Object URL 显示；不发送到服务器。
2. Canvas 按设置的宽度缩小绘制图片，高度按原图宽高比计算。每个缩小后的像素对应一颗拼豆。
3. 对每个像素，在当前启用的内置颜色中寻找距离最近的颜色。当前使用加权 RGB 平方距离（R×2、G×4、B×3），并非实体品牌色卡或 CIEDE2000。
4. 按最近色替换像素、累计各颜色用量，再把小图放大为最近邻像素图，并按设置叠加网格。PNG 与 SVG 使用同一缩放比例和相同的标题、图案、图例布局参数。
5. 结果转为 PNG，浏览器本地下载；控制参数变化时重新执行转换并更新预览与用量。

RGB 色板从已缩小的图片中提取：将颜色归并到 8 的倍数，按出现频率取前 N 种颜色，再将每颗拼豆映射至最近的 RGB 色值。图例和导出均显示完整 RGB(r, g, b) 数值与用量。

用量标题使用「拼豆用量清单」。透明图片先合成到白底；每个网格位置都映射到一种颜色并计为一颗。颜色统计从最终渲染格子颜色数组汇总；清单总数、预览尺寸与导出尺寸均以实际处理后的整数网格宽高为准，合计应等于实际宽度 × 高度。图片处理有异步回调时，忽略过期请求，防止旧设置结果覆盖新图案。

## 自有色板规划（待实现）

- 增加「色板管理」，用户可建立并命名自己的拼豆色板，只从当前色板里的可用豆色生成图案，避免清单要求购买手头没有的颜色。
- 每个色板颜色至少记录：自定义色号/标签、显示名称（可选）、实际颜色值（HEX）。色号用于识别实体豆；HEX 用于图像匹配。只输入色号无法推断颜色，除非选用已知品牌的内置色卡。
- 添加颜色同时支持颜色选择器与手动 HEX 输入；可编辑、删除、启用或暂时停用颜色。颜色数量设置改为色板可用色数上限，不能超过启用颜色数量。
- 支持色板 JSON 导入/导出作为完整备份格式；之后可增加 CSV，方便用表格批量整理。导入时校验 HEX、必填色号和重复项，并提供错误提示，不静默丢弃数据。
- 色板保存在浏览器本地，刷新后仍可使用；导出的拼豆图例显示用户的色号/名称和每色颗数，同时保留 HEX 辅助辨认。
- 图像匹配只在已启用色板颜色中进行；统计必须从最终映射格子汇总。色板为空或导入内容无有效颜色时，不生成图案并提示先补充色板。
- 可选的增强方案：展示每种目标颜色映射到的实体豆颜色，并允许用户手动指定替代色后重新生成；可标记色差明显的映射，便于用户检查。拍照取色可以作为辅助入口，但不能替代手动 HEX 校正，因为光线和相机白平衡会影响照片颜色。

### 选色交互建议

- 以颜色卡片网格为主要入口，不要求用户先理解或输入 HEX。每张卡以大色块为主，下面显示色号/名称；选中状态清楚，支持点按多选。
- 色板较大时提供搜索色号/名称、按色系筛选和「只看已选」；顶部显示已选数量，并提供全选、清空、恢复默认等快捷操作。
- 「添加颜色」提供两种并列方式：颜色选择器选色、输入 HEX；实时显示色块预览，并单独填写实体豆色号/名称。避免把色号文本误当作颜色值。
- 提供「从图片取样」作为快捷补色：用户点原图或缩略图中的颜色，系统将它匹配到现有豆色；若色差较大，提示结果并让用户确认。取样色本身不直接当作可用实体豆色。
- 生成预览后展示颜色替换关系（原图取样色 → 实际使用的豆色），允许用户为某个取样色手动改选替代豆色，并即时更新图案和用量。
- 建议将色板设置放在独立弹窗或侧栏中，图案预览继续可见；让用户选色时能直观看到图案变化，避免来回跳页。
