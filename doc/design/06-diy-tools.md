# 06 · DIY 功能与工具

## 定位

个人主页保留轻量、可即时使用的小工具；较大的创作型功能使用独立入口和独立页面承载，避免把复杂操作挤进主页栏目。

## 页面层级

- 主体导航保留「DIY 工具」：文字计数、JSON 格式化等轻量工具继续留在现有页面。
- 新增「DIY 功能」栏目作为大型功能导航页，以卡片介绍每项功能。
- 点击大型功能卡片后进入独立全屏页面，拥有自己的 URL 和页面布局。
- 图片转拼豆图作为首个大型功能入口，提供图片上传、拼豆宽度、自有色板选色、网格预览、颜色用量和多格式导出。
- 独立工具页使用轻量的主题化 Header、工作区 Body 和 Footer；显示作者 Abin，并可返回 DIY 功能目录。
- 转换在浏览器 Canvas 中完成，图片不上传到服务器。
- 拼豆功能页独立显示带头像的 Abin 标识与 DIY STUDIO 名称；页脚提供联系邮箱、改进/问题反馈邮件入口和返回功能目录。主站首页的 Header 与 Footer 不随此工具页改动。

## 实现约定

- 使用 Vue Router 管理独立功能页路由，支持直接访问和刷新。
- 功能目录与轻量工具页分开，保留现有文字计数和 JSON 格式化交互。
- 页面颜色延续 Forest Bloom 的雾蓝、柔粉与暖白色，但独立功能页可按功能需要扩展自己的布局。
- 每次项目讨论或实现后，将确定的设计决策和范围同步记录到 `doc/`。

## 拼豆转换参考

- [BeadMapper](https://www.beadmapper.com/) 展示了图片上传、颗粒尺寸、调色板、结果预览和导出的典型流程，可作为交互参考。
- [PatternBeads](https://www.patternbeads.com/pattern-maker) 以实体拼豆调色板进行颜色匹配，说明颜色映射应优先对齐实际可用的拼豆颜色。
- 提供「个人色库 / 图片原色」两种颜色来源。个人色库模式只使用用户启用的实物豆色；图片原色模式从缩小后的图像提取主要颜色，不保证对应手头的实体豆。
- 已选图片时，拼豆宽度、颜色数和网格开关均需在拖动或切换时实时更新预览与颜色统计，不要求用户额外点击生成按钮。
- 拼豆宽度支持 16–256 颗，滑块旁提供数字输入并联动更新；个人色库模式的颜色种类由用户启用的自有色板决定，图片原色模式可设置 4–128 色上限。
- PNG、PDF、SVG 导出均由拼豆图和颜色用量图例组成，图例记录当前选定色值格式及所需颗数。
- 提供「导出时显示我的头像和名字」开关，默认开启并随工作区保存；开启时在导出图标题区以低调头像和「Abin」名字署名。关闭时完全隐藏署名，并恢复原始紧凑标题布局。PNG、PDF、SVG 使用相同的布局逻辑，SVG 内嵌头像图片以便离线查看。
- 导出格式以 PNG、PDF、SVG 三个 Radio 单选项呈现，默认选中 PNG。
- PNG、PDF、SVG 均直接下载，不打开预览或打印窗口；PDF 由拼豆画布的 JPEG 图像数据封装成单页 PDF 文件，SVG 适合平板缩放查看，三种格式均附颜色用量图例。
- PNG/PDF 的画布导出先完成头像署名绘制，再绘制图案与用量图例；头像加载完成后继续导出，署名坐标由同一导出作用域共享。
- 每种导出格式在单选项旁说明适用场景；SVG 必须以 SVG 矩形元素逐颗绘制拼豆和网格，不可将 PNG 当作图片嵌入。SVG 与 PNG 共用标题、图案缩放尺寸、上方留白、下方三列图例、色块尺寸、文字和间距，保持版式基本一致。
- 导出格式的补充说明需使用浅雾蓝底色、柔和边线和易读行距，明确指出各格式的使用理由。
- 三个格式选项及说明始终同时显示，采用等宽固定网格；切换只改变选中样式，不改变布局尺寸。
- 色值显示格式固定选项同样使用该单选卡片样式，顺序为 #RRGGBB、RGB(r, g, b)、0xRRGGBB，默认 #RRGGBB；选择同步作用于预览和所有导出格式。

## 当前转换实现

1. 文件通过浏览器文件输入读取，并以本地 Object URL 显示；不发送到服务器。
2. Canvas 按设置的宽度缩小绘制图片，高度按原图宽高比计算。每个缩小后的像素对应一颗拼豆。
3. 对每个像素，在用户色板中启用的颜色里寻找距离最近的颜色。当前使用加权 RGB 平方距离（R×2、G×4、B×3），并非 CIEDE2000。
4. 按最近色替换像素、累计各颜色用量，再把小图放大为最近邻像素图，并按设置叠加网格。PNG 与 SVG 使用同一缩放比例和相同的标题、图案、图例布局参数。
5. 结果转为 PNG，浏览器本地下载；控制参数变化时重新执行转换并更新预览与用量。

个人色库模式下，图案颜色来自已启用的用户色板；图片原色模式下，把缩小图像的颜色按 8 为步长归并，取频率最高的 N 种，再将每颗拼豆映射至其中最近的颜色。两种模式均统计最终格子，并生成用量图例。个人色库图例显示用户色号和名称；图片原色模式使用 IMG-01 等临时色号。

用量标题使用「拼豆用量清单」。透明图片先合成到白底；每个网格位置都映射到一种颜色并计为一颗。颜色统计从最终渲染格子颜色数组汇总；清单总数、预览尺寸与导出尺寸均以实际处理后的整数网格宽高为准，合计应等于实际宽度 × 高度。图片处理有异步回调时，忽略过期请求，防止旧设置结果覆盖新图案。

## 自有色板与选色交互

- 增加「色板管理」，用户可建立并命名自己的拼豆色板，只从当前色板里的可用豆色生成图案，避免清单要求购买手头没有的颜色。
- 每个色板颜色至少记录：自定义色号/标签、显示名称（可选）、实际颜色值（HEX）。色号用于识别实体豆；HEX 用于图像匹配。只输入色号无法推断颜色，除非选用已知品牌的内置色卡。
- 添加颜色同时支持颜色选择器与手动 HEX 输入；可编辑、删除、启用或暂时停用颜色。个人色库模式最多使用全部已启用颜色；图片原色模式单独设置提取颜色数上限。
- 支持色板 JSON 导入/导出作为完整备份格式。导入时校验 HEX、必填色号和重复项，并提供错误提示，不静默丢弃数据。
- 色板保存在浏览器本地，刷新后仍可使用；导出的拼豆图例显示用户的色号/名称和每色颗数，同时保留 HEX 辅助辨认。
- 图像匹配只在已启用色板颜色中进行；统计必须从最终映射格子汇总。色板为空或导入内容无有效颜色时，不生成图案并提示先补充色板。
- 可选的增强方案：展示每种目标颜色映射到的实体豆颜色，并允许用户手动指定替代色后重新生成；可标记色差明显的映射，便于用户检查。拍照取色可以作为辅助入口，但不能替代手动 HEX 校正，因为光线和相机白平衡会影响照片颜色。

### 选色交互建议

- 以颜色卡片网格为主要入口，不要求用户先理解或输入 HEX。每张卡以大色块为主，下面显示色号/名称；选中状态清楚，支持点按多选。
- 色板较大时提供搜索色号/名称、按色系筛选和「只看已选」；顶部显示已选数量，并提供全选、清空、恢复默认等快捷操作。
- 「添加颜色」提供两种并列方式：颜色选择器选色、输入 HEX；实时显示色块预览，并单独填写实体豆色号/名称。避免把色号文本误当作颜色值。
- 提供「从图片取样」作为快捷补色：用户点原图或缩略图中的颜色，系统将它匹配到现有豆色；若色差较大，提示结果并让用户确认。取样色本身不直接当作可用实体豆色。
- 生成预览后展示颜色替换关系（原图取样色 → 实际使用的豆色），允许用户为某个取样色手动改选替代豆色，并即时更新图案和用量。
- 色板管理直接放在图案预览下方，用户修改启用颜色后会实时重算，保持预览可见。
- 当前已实现自定义色板的添加、编辑、停用、删除、搜索、启用筛选、本地保存和 JSON 导入/导出。没有预置色卡，避免把用户未持有的颜色误当成可用拼豆。
- 原图取样会建立取样色到所选实体豆色的手动映射；图案转换和用量统计使用替代色，导出图例显示用户的色号与名称。
- 颜色来源开关位于工具控制区，默认个人色库；切换模式和调整图片颜色上限时实时重算图案。原图取样只在个人色库模式显示和生效。
- 个人色板管理只在个人色库模式显示；图片原色模式隐藏色板管理区，避免展示当前不参与转换的颜色设置。

## 页面说明与重置

- 工具页顶部提供「功能简介」弹窗，集中说明上传、颜色来源、色板维护、网格与颗粒外观、拼豆模式、坐标定位和导出能力。
- 顶部「清除缓存并重置」在二次确认后只清除本工具的个人色板和工作区 `localStorage` 数据，不影响其他站点数据；随后重新加载页面恢复默认设置。功能简介也说明此重置范围。
- 在「显示拼豆网格」下方提供「显示拼豆颗粒」开关：每格以带白色中心孔的圆形豆粒显示。白色中心孔在浅色豆和打印图纸上更清楚；该外观选项只影响预览与导出，不改变每格一颗的用量统计。PNG/PDF 与 SVG 都应呈现一致的颗粒样式。
- 增加「拼豆模式」全屏参考视图，提供「完整显示」（按可用短边适配，可能留白）与「铺满屏幕」（按长边放大，边缘可能裁切）两种适配方式。模式中可逐色隐藏/显示，隐藏只影响参考画面，不改图案数据和用量。
- 拼豆模式的颜色控制使用可折叠的多列色卡面板，支持搜索、单色切换和「一键显示 / 一键隐藏」，避免大量色号挤成单行难以查找。
- 坐标提示同时显示当前格子的豆色样本和标签，隐藏状态也明确标出。拼豆模式色卡标签提供「导出色值 / 颜色名称 / 实物色号」三种显示方式，默认跟随导出色值格式；标签偏好写入工作区本地存档。
- 拼豆模式主画面使用独立 SVG 矢量图；提供缩放滑块、放大/缩小按钮、滚轮缩放和拖动平移。适配切换重置缩放和平移；隐藏颜色、缩放和最后的平移位置自动保存。
- 拼豆模式工具栏也提供「网格」和「拼豆颗粒」开关，直接控制 SVG 参考图并自动保存设置。
- 拼豆模式全程为每一列和每一行显示坐标：列按 Excel 字母（A…Z、AA…）标记，行从 1 开始，沿用原有简洁标记样式。指针所在或点选的格子显示如「D12 / 第 12 行、第 4 列」，并高亮该格。高倍率时增加可点击的小型全图缩略图，标出当前视口区域并支持快速跳转。
- 自动将当前格子颜色、尺寸、来源模式、颜色上限、网格、颗粒外观、导出选项、色值格式、色卡标签模式、手动映射、隐藏颜色和适配方式保存到 `localStorage`；同时保存最长边缩至 1200px 的 JPEG 原图副本，以便下次进入时恢复图案并继续调整。图案画面从格子数据重新绘制，不单独存储大张预览 PNG。
- 图片原色模式建议最多 128 色；单边图案宽度建议最多 256 格，默认值保持 48 格。后续应补充总格数上限（建议约 65,536 格），并在保持原图宽高比的前提下约束极端长宽比图片，避免生成过大的画布与用量表。
