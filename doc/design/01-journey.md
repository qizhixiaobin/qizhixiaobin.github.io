# 01 · 经历页面（Journey）

## 页面定位

这是网站默认首页（`/`）。通过一条非线性的个人时间轴，让访问者快速理解“我从哪里来、正在做什么、在乎什么”。它不应写成传统简历：每个阶段着重一个变化、感受或获得的能力。

## 页面内容

1. **首屏叙事**：一句个人主张、简短引言和当前身份。
2. **时间轴**：开始接触技术、大学、工作与未来等阶段。
3. **阶段详情**：年份、阶段标题、地点/身份、故事、关键词和可选图片。
4. **当前状态**：正在学习、正在做、最近喜欢的事；可作为时间轴后的收束模块。

## 技术设计

| 范围 | 技术 | 用途 |
| --- | --- | --- |
| 页面 | Vue 3 SFC（`JourneyView.vue`） | 使用 `<script setup lang="ts">` 管理页面数据和交互 |
| 展示 | `v-for` + `:key` | 根据经历数组渲染节点，避免重复手写 HTML |
| 组件 | `JourneyTimeline.vue`、`JourneyStage.vue` | 时间轴骨架与单个阶段卡片分离 |
| 数据 | `src/data/journey.ts` | 使用 TypeScript 类型约束年份、标题、文本、标签和图片 |
| 动效 | CSS transition / IntersectionObserver | 进入视口时淡入；不依赖重量级动画库 |

```ts
export interface JourneyStage {
  year: string
  title: string
  subtitle: string
  story: string
  tags: string[]
  featured?: boolean
}
```

## 交互规则

- 桌面端显示横向三列时间轴；移动端变为纵向阅读流。
- 点击阶段卡片可展开完整故事；初版可以仅展示摘要。
- 当前阶段使用柔和背景与“正在发生”标签区分，但不应干扰阅读。
- 首屏到时间轴的引导使用普通锚点滚动，不劫持鼠标滚轮。

## 数据与内容规范

- 每个阶段控制在 60–120 字；长故事以笔记链接承接。
- 年份使用范围，例如 `2020—2024`；尚未结束使用“至今”。
- 不公开的经历不放入前端仓库，GitHub Pages 上的源文件和构建产物均可被访问。

## 完成标准

- 访问 `/` 可直达该页并刷新不丢失内容。
- 时间轴在 375px、768px、1440px 宽度下没有横向溢出。
- 键盘能够聚焦并展开任何互动卡片。
