# 04 · 地图页面（Map）

## 页面定位

路径为 `/map`。用于标记生活过、旅行过和想去的地方。第一版追求“个人地图”的叙事感，而不是导航功能。

## 页面内容

1. 抽象地图画布与地点标记。
2. 地点状态：去过、生活过、想去。
3. 选中地点后显示时间、短故事、关联照片或笔记。
4. 地图下方的地点清单，确保不依赖视觉位置也能阅读内容。

## 技术设计

| 阶段 | 技术 | 用途 |
| --- | --- | --- |
| 原型 | CSS 背景 + 绝对定位的按钮 | 快速验证排版与叙事 |
| 第一版 | 内联 SVG + Vue `v-for` | 以坐标绘制可控、风格统一的自定义地图 |
| 进阶版 | Leaflet + OpenStreetMap | 需要缩放、拖拽、真实地理位置时再接入 |
| 数据 | `src/data/places.ts` | 地点元数据与显示坐标分离 |

```ts
export interface Place {
  id: string
  name: string
  status: 'lived' | 'visited' | 'wish'
  coordinates: { x: number; y: number }
  date?: string
  story: string
  noteSlug?: string
}
```

## 交互与无障碍

- 标记必须是 `<button>`，而不是不可聚焦的 `span`。
- 选中标记后更新侧栏或弹层，并将当前地点显示为 `aria-pressed`。
- 在小屏幕上地图高度固定，地点详情显示在地图下方；不使用难以关闭的浮层。
- 地点坐标仅用于绘制，不公开精确住址或敏感行程。

## 何时引入 Leaflet

只有同时满足以下任意两项时再引入：需要真实世界地图、需要缩放/拖拽、地点超过 30 个、需要路线或聚合。否则自定义 SVG 更轻、也更贴合网站视觉。

## 完成标准

- 鼠标、键盘和触屏都能选择地点。
- 状态使用文字和颜色共同表达。
- 地图不可用时，地点清单仍保留全部信息。
