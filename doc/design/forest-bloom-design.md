# Forest Bloom · 个人数字花园

## 1. 产品定位

一个以「人生经历」为入口的个人网站：不是简历的堆叠，而是一座可以被慢慢浏览的数字花园。网站承载经历、兴趣、笔记与足迹，整体气质安静、温暖、有自然生长感。

### 核心页面

| 栏目 | 目标 | 核心内容 |
| --- | --- | --- |
| 经历 | 默认首页，建立对“我”的理解 | 时间轴、阶段故事、关键词 |
| 兴趣 | 展现生活中的持续热爱 | 兴趣卡片、正在做的事 |
| 笔记 | 沉淀思考和学习 | 标签、文章列表、阅读时长 |
| 地图 | 记录足迹和愿望 | 地点、状态、故事 |

## 2. 页面结构

```text
┌─────────────────────────────────────────────────────────┐
│ Profile Header  封面 / 头像 / 名称 / 简介 / IP / 导航    │
├─────────────────────────────────────────────────────────┤
│                                                         │
│ Body  当前栏目内容（默认：经历）                         │
│       点击导航时：旧内容向左淡出，新内容从右侧滑入        │
│                                                         │
├─────────────────────────────────────────────────────────┤
│ Footer  邮箱 · GitHub · 现在所在地 · © 年份              │
└─────────────────────────────────────────────────────────┘
```

Header 参考短视频个人主页的信息密度，但不复制其 UI：顶部是一张带撞色抽象背景的个人档案横幅；头像在左下方跨越封面和资料区，文字资料全部右对齐，导航在资料区下方。移动端保留信息层级并允许导航横向滚动。Footer 不悬浮，始终位于页面内容之后。

## 3. 视觉语言

### 色彩

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--ink` | `#263B47` | 标题、主要文字，平衡两种主色 |
| `--moss` | `#6A90A6` | 雾蓝主色：导航当前态、链接、认证 |
| `--leaf` | `#B7CBD2` | 雾蓝浅阶：装饰和次要强调 |
| `--petal` | `#F2B6B6` | 柔粉撞色：封面、重点节点、提示 |
| `--paper` | `#FFFAF8` | 带暖意的白色页面底色 |
| `--mist` | `#EDF2F3` | 冷调卡片与分隔背景 |

### 字体与间距

- 中文：`Noto Serif SC`（标题）与系统无衬线字体（正文）。
- 英文和数字：`DM Mono`，用于时间、章节和标签。
- 基础间距单位：4px；常用间距：12 / 20 / 32 / 48 / 72px。
- 圆角：小组件 12px、卡片 20px、胶囊标签 999px。

### 动效

- 页面切换：`transform: translateX()` + `opacity`，420ms，缓入缓出。
- 卡片 hover：上移 4px，180ms。
- 支持 `prefers-reduced-motion`：禁用非必要动画。

## 4. 组件清单

| 组件 | 责任 |
| --- | --- |
| `ProfileHeader` | 封面、头像、名称、简介、IP/所在地、栏目导航 |
| `PageTransition` | 按导航方向完成栏目切换 |
| `JourneyTimeline` | 经历节点及阶段详情 |
| `InterestCard` | 兴趣名称、进度、描述 |
| `NoteCard` | 笔记元数据与阅读入口 |
| `MapPin` | 地点状态和地点故事 |
| `AppFooter` | 联系方式与外部链接 |

## 5. 原型约束与后续实现

当前原型用前端本地数据驱动，专注布局、色彩、响应式与交互。第二阶段再将页面拆为 Vue Router 路由，并把经历/笔记迁到 Markdown 或 TypeScript 数据文件。地图第一版使用抽象 SVG 画布与地点卡片，暂不接入第三方地图服务。
